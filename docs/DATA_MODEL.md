# Data model

PostgreSQL 16 via Drizzle ORM. Schema source: `packages/db/src/schema/*.ts`; migrations in `packages/db/migrations/`. All timestamps are `timestamptz` in UTC. IDs are text (Better Auth generates its own; our code uses UUIDs).

## Entity overview (Phase 0)

```
user ──< session            (activeWorkspaceId → workspace)
user ──< account            (credential password hash, OAuth tokens)
verification                (email verification, password reset, magic link tokens)

workspace ──1 workspace_settings
workspace ──< membership >── user
workspace ──< invitation    (inviterId → user)
```

## Tables

### `user` (Better Auth core + profile preferences)

| Column | Type | Notes |
| --- | --- | --- |
| id | text PK | |
| name | text | |
| email | text unique | lower-cased by Better Auth |
| email_verified | boolean | sign-in requires `true` |
| image | text? | avatar URL in S3 |
| timezone | text? | IANA; null = inherit workspace |
| date_format | text? | one of `DATE_FORMATS` in core; null = inherit |
| time_format | text? | `12h` / `24h`; null = inherit |
| week_start | smallint? | 0 = Sunday … 6 = Saturday; null = inherit |
| created_at, updated_at | timestamptz | |

### `session`, `account`, `verification`

Standard Better Auth tables. `session.active_workspace_id` is the organization plugin's `activeOrganizationId` renamed. Indexes on `session.user_id`, `account.user_id`, `verification.identifier`.

### `workspace` (Better Auth `organization`)

| Column | Type | Notes |
| --- | --- | --- |
| id | text PK | |
| name | text | |
| slug | text unique | URL segment `/w/[slug]`; generated by `slugify` + numeric suffix |
| logo | text? | |
| metadata | text? | JSON string reserved by Better Auth |
| created_at, updated_at | timestamptz | |

### `workspace_settings`

One row per workspace, created in the same transaction as the workspace.

| Column | Type | Default |
| --- | --- | --- |
| workspace_id | text PK → workspace (cascade) | |
| timezone | text | `UTC` |
| week_start | smallint | `1` (Monday) |
| time_format | enum `time_format` (`12h`, `24h`) | `24h` |
| duration_format | enum `duration_format` (`hh:mm:ss`, `hh:mm`, `decimal`) | `hh:mm:ss` |
| currency | char(3) | `USD` |

### `membership` (Better Auth `member`)

| Column | Type | Notes |
| --- | --- | --- |
| id | text PK | |
| workspace_id | text → workspace (cascade), indexed | |
| user_id | text → user (cascade), indexed | |
| role | enum `workspace_role` (`owner`, `admin`, `manager`, `member`) | |
| status | enum `membership_status` (`ACTIVE`, `INVITED`, `DEACTIVATED`) | `ACTIVE`. `INVITED` is reserved; pending invites live in `invitation` |
| created_at, updated_at | timestamptz | |

Unique `(workspace_id, user_id)`.

### `invitation`

| Column | Type | Notes |
| --- | --- | --- |
| id | text PK | the invite link is `/invite/[id]` |
| workspace_id | text → workspace (cascade), indexed | |
| email | text, indexed | must match the accepting user's email |
| role | text | role granted on acceptance |
| status | text | `pending`, `accepted`, `rejected`, `canceled` |
| expires_at | timestamptz? | 7 days |
| inviter_id | text → user | |
| created_at | timestamptz | |

## Enums

`workspace_role`, `membership_status`, `time_format`, `duration_format` — values come from `packages/core` constants so TypeScript and Postgres agree.
